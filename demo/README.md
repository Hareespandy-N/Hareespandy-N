# Smart Factory Flow — Synthetic Interoperability Simulator

**A small, original, deterministic example** of how an AMR, automated storage system, cobot, PLC and SCADA can coordinate a material-handling workflow. **Nothing here connects to production hardware.**

### What it demonstrates

- Normal material transfer across orchestrated subsystems
- Missing rack/container alarm that stops downstream execution
- PLC interlock rejection that prevents robot transfer
- Charger readiness rejection that holds mission execution
- Explicit event records suitable for debugging and UI playback

### Run locally

Python 3.10+ and standard library only:

```bash
python demo/engine.py --scenario normal
python demo/engine.py --scenario missing_rack --json
python -m unittest discover -s demo -p 'test_*.py' -v
```

Browser playback: open [`docs/index.html`](../docs/index.html) in a modern browser. It includes precomputed traces generated by the Python engine and runs completely offline.

### What it is not

- Not a real control program, PLC driver, ASRS gateway or fleet manager
- Not connected to any customer service, robot, battery, charger or industrial network
- Not a functional-safety implementation or a substitute for safety-rated controls
- Timings and all values are illustrative, not measured production performance

### Event model

Each event carries `time_s`, `system`, `action`, `status` and `detail`. Every scenario returns `complete`, `alarm`, and an ordered list of events. Inhibited downstream actions never appear in failure traces.
